# Testing

Discover actual commands from the target project. For behavior changes, use focused failing tests before implementation where supported, then run relevant tests and configured static/build checks. Do not claim tooling tests validate the application.
Verify critical user journeys in a browser, including applicable error, responsive, keyboard and focus behavior. Record commands, results and evidence paths. Missing environments or unavailable checks are not passing results.
Submit test and browser evidence through frontend-verify before human acceptance. Keep tests proportional to the changed behavior.
