# Theming guidance

- Use the theme mechanism selected by the project.
- Keep theme-specific values at a shared semantic layer when the project uses CSS variables.
- Ensure the selected theme is applied on initial render and changes accessibly.
- Persist only the minimum preference needed and handle unavailable storage safely.
- Check keyboard access, visible focus, contrast, responsive states, and reduced motion across supported themes.
- Treat browser screenshots as project-owned reviewed baselines, not generated truth.
