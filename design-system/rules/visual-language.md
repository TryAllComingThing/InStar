# Visual language

Use the project's existing visual language as the baseline. The project owns its brand, palette, typography, density, and styling technology.

- Establish a clear hierarchy between page title, section heading, supporting text, and primary action.
- Use color to communicate meaning consistently; do not rely on color alone to convey status.
- Keep typography readable and consistent with the product's established scale and content needs.
- Reuse existing spacing, sizing, and surface conventions when available. Do not impose a new shared styling system or fixed numeric scale on a project that has not adopted one.
- Avoid decorative effects that reduce legibility or compete with primary content.
- Check text wrapping, long labels, empty states, and dense data layouts with realistic content.
