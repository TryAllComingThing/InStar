# Layout and responsive behavior

- Follow the target project's existing page and breakpoint conventions.
- Prioritize content order and task completion across viewport sizes; do not merely shrink a desktop layout.
- Prevent horizontal overflow, clipped controls, and inaccessible navigation at narrow widths and browser zoom.
- Keep related information grouped and align repeated elements consistently.
- For data-dense screens, preserve scanability and make overflow behavior deliberate.
- Validate layouts with representative content, including long labels, missing data, and the largest expected collections.
