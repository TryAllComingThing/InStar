# Dark Theme Reference

Advisory checklist for an explicitly supported dark theme. This guide does not create a theme engine or define colors.

- Confirm the project defines dark-theme token mappings and the intended activation behavior.
- Check text, borders, overlays, charts, focus indicators, and disabled states in the dark surface context.
- Preserve semantic meaning across themes; do not mechanically invert every color.
- Verify images, shadows, elevation, and opacity against the supplied reference.
- Test the relevant pages and states in the actual dark theme when a browser environment is available.

Use only when the project supports or the task explicitly requests a dark theme.
