# Wholesale Theme Reference

Advisory checklist for wholesale, distribution, and operational catalog experiences. This is not a default theme or a token palette.

- Prioritize product identification, price, availability, quantity, and fulfillment details according to the approved requirements.
- Preserve efficient scanning and bulk actions in large catalogs.
- Check responsive behavior for dense tables, filters, and product cards.
- Use existing project tokens for brand, pricing, inventory, and status roles; do not assign new meanings to tokens without evidence.
- Verify loading, unavailable, minimum-order, and validation states when they appear in the reference.

Use only when the project or task identifies a wholesale experience.
