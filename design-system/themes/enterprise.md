# Enterprise Theme Reference

Advisory checklist for products whose approved direction emphasizes trust, clarity, and dense workflows. This is not a default theme or a token palette.

- Keep information hierarchy and status meaning clear in data-heavy screens.
- Check contrast and distinguish interactive states without relying on color alone.
- Use the project's existing semantic surface, text, border, and status tokens.
- Avoid decorative effects that reduce scanability or conflict with the supplied brand direction.
- Confirm tables, filters, dialogs, and empty/error states against the high-fidelity reference.

Use only when the project or task identifies an enterprise visual direction.
