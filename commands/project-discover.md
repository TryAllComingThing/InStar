description: Extract an existing project's engineering baseline with source evidence and conflict reporting.
---

Use `$project-discover` to analyze architecture, API, database, coding and runtime
constraints. State the project and scope; generate artifacts only when requested.
Default output is docs/project-baseline/INDEX.md and six independently readable
domain documents, with separate evidence and collection notes. Design/development
read the index and applicable domains rather than a complete discovery report.
Discovery preserves project policy and does not automatically adopt inferred rules.
