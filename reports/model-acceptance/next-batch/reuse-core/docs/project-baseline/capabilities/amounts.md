# Amount display
CAP-BILLING-AMOUNT formats dollar input with toFixed(2) and a $ prefix. CAP-SETTLEMENT-AMOUNT divides cent input by 100 then formats similarly. Both are named exports; no consumers or tests were found. Owners inferred: billing and settlement. No explicit validation, locale handling or currency selection. Settlement comments require integer cents but implementation does not enforce it. Number rounding behavior applies; billing non-number input may throw, settlement coercion may occur. No state, resources or transactions. Identical names do not imply compatible units: input 100 means $100.00 versus $1.00. Preserve separate domain contracts.
