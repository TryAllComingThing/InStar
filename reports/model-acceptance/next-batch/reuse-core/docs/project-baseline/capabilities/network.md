# Network
CAP-NETWORK-REQUEST exports request only through src/network/index.mjs. request(path, transport) calls injected transport once with x-client: orders, then awaits response.json(). Non-ok response throws Error(REQUEST_FAILED); transport and JSON errors propagate. No retries, cancellation, caching, authentication or input validation are implemented. No state or transactions. Transport owns connection/resource lifecycle; no cleanup guarantee is shown. Public consumers may use index.mjs; headers is private even though its file exports it. Real consumer: orders/list.mjs. Test: test/requests.test.mjs covers list path and header only. Owner inferred: network. Hash coverage includes implementation, headers, boundary rule and test.
